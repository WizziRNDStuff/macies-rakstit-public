# Mācāmies rakstīt burtus ✏️

Bezmaksas latviešu burtu rakstīšanas treniņš bērniem — velc burtu pa pelēko
ēnu ar pirkstu vai pildspalvu. Trīs grūtības līmeņi, visi 33 alfabēta burti,
lielie un mazie.

**Spēlēt:** https://wizzirndstuff.github.io/macies-rakstit-public/

Darbojas planšetē, telefonā un datorā, tieši pārlūkā — nekas nav jāinstalē.

---

A free Latvian handwriting practice app for kids. Trace the letters over the
grey shadow with a finger or stylus. Three difficulty levels, all 33 letters
of the Latvian alphabet, upper and lower case. Runs in any browser.
